# TenantSinkType

The subset of `SinkType` a Domain may declare. The platform's own backends exist as built-in sinks and are never authored by a tenant, so a request body accepts the two forwarding protocols only. 

## Enum

* `OTLP` (value: `'otlp'`)

* `SYSLOG` (value: `'syslog'`)
